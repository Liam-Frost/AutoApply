# Ashby

- The posting's address + /application opens the form. One page, no account, "Submit Application" at the bottom.
- "Autofill from résumé" is at the top: use it first, then correct.
- Yes/No questions are pairs of buttons (pressed / not pressed), not radio buttons. Labels of different questions
  can share ids: after clicking one, check that the right question changed.
- Lists that search ("Start typing…"): click the box, type, wait for the options, click one.
- A deadline is shown in the viewer's own time zone.
- Some employers have a single file field: merge what the posting asks for into one PDF and say so in the
  free-text box. Some limit how many applications a person may send in a period: the page says so.
