# Greenhouse

- Usually no account. One page: contact, résumé, optional cover letter, links, the employer's own questions, voluntary
  self-identification, then "Submit application". A thank-you page follows.
- On an employer's own careers site the form often sits in a frame from greenhouse.io: open the frame's address.
- File fields are hidden inputs behind "Attach" buttons; there may also be "Enter manually". Check the file name shown.
- Lists are search boxes with a panel of options (type a distinctive part, then pick). Location boxes search too.
- Some employers ask for a code sent by e-mail after "Submit": read it from the mailbox and enter it.
