# Amazon (amazon.jobs)

- Needs an Amazon Jobs account. The applicant's applications: /en-US/applicant/dashboard/applications (Active:
  drafts and in progress; Archived: past).
- A wizard: Contact, SMS (skip), General questions, Education, Job-specific, Work eligibility, Résumé,
  Acknowledgement, EEO, Military/Veteran, Review & submit.
- Answers are shared between a person's applications: every section may hold what another application left there.
  Go through each one; some radio buttons come back unset every time.
- The résumé step has "Replace"; once uploaded the file stays for later applications.
- Job-specific questions are native lists, multi-selects and short text boxes (200 characters at most).
- The acknowledgement is a legal attestation; the sections after it stay locked until it is ticked.

- On Verify your email, request the code on Amazon, then use the read-only mail tool. If no fresh email is found, wait briefly and check again. Use the fresh Amazon message for this challenge. If the mailbox cannot be read or the fresh message never arrives, ask the applicant for the code (ask_code).
