The Timeline tab of an application was a list of lines with the same weight, each beginning with "Email:" and a long subject. It is now a time line: the days it happened on, one line with a node per event, its kind by its icon (mail, a stage, an interview, an assessment, documents asked for, the agent's runs), and in a quiet colour what moved the application on - a stage, an invitation, an offer, a request, a rejection - while confirmations and runs stay quiet. Each event says what it was in a few words, with the email's summary below; click one for its subject and sender, and to show it on the Mail tab.
